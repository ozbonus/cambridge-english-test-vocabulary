# Cambridge English Vocabulary

A dataset of officially recommended vocabulary for the Cambridge YLE, KET, PET, and FCE English tests.

The dataset so far just covers the Cambridge Young Learners English (YLE) and Key for Schools English Test (KET). Other tests will come later, but possibly not before I need them. If *you* have a request, then send me an email and I'll look into it.

## Sources

The vocabulary for this dataset has been source from materials provided freely by Cambridge University Press.

1. Cambridge Assessment English. (2018). Pre A1 starters, A1 movers and A2 flyers word lists: For exams from 2018 [Manual]. Cambridge Assessment English / University of Cambridge Local Examinations Syndicate (UCLES). <https://www.cambridgeenglish.org/images/149681-yle-flyers-word-list.pdf>

2. Cambridge Assessment English. (2025). A2 Key and A2 Key for Schools Vocabulary List [Manual]. Cambridge Assessment English / University of Cambridge Local Examinations Syndicate (UCLES). <https://www.cambridgeenglish.org/images/506886-a2-key-2020-vocabulary-list.pdf>
